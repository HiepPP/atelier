# M1 - File Explorer Và Read-Only Viewer

Các bước code cụ thể cho mốc M1 trong `PLAN.md`. Mục tiêu: cây thư mục lazy (NSOutlineView) + viewer read-only (TextKit 2), gắn vào WorkspaceView của M0.

Xong khi: duyệt cây mượt, expand mới đọc thư mục con, click file mở nội dung read-only monospaced, file lớn/binary không treo.

## Cấu Trúc File

```text

  FileTreeView.swift        // NSViewRepresentable bọc NSOutlineView
  FileTreeCoordinator.swift // DataSource + Delegate

  IgnoreRules.swift         // danh sách bỏ qua (.git, node_modules...)
```

## Bước 1 - Model Node

- `FileNode` giữ URL, cờ thư mục, tên, và children lazy (nil khi chưa load).
- Children chỉ đọc khi node được expand, không đọc trước.

```swift
final class FileNode {
    let url: URL
    let isDirectory: Bool
    var name: String { url.lastPathComponent }
    var children: [FileNode]?    // nil = chưa load
    init(url: URL, isDirectory: Bool) { ... }
}
```

## Bước 2 - Vì Sao Dùng NSOutlineView

- SwiftUI `List`/`OutlineGroup` load kém với cây lớn và cuộn không mượt.
- `NSOutlineView` cho lazy expand thật và view reuse. Bọc qua `NSViewRepresentable`.

## Bước 3 - Lazy Load Trong DataSource

- `FileTreeCoordinator: NSObject, NSOutlineViewDataSource, NSOutlineViewDelegate`.
- `outlineView(_:numberOfChildrenOfItem:)` và `child(_:ofItem:)` đọc thư mục con lần đầu khi cần, cache vào `node.children`.
- `isItemExpandable` = `node.isDirectory`.

```swift
func loadChildren(_ node: FileNode) -> [FileNode] {
    if let c = node.children { return c }
    let urls = (try? FileManager.default.contentsOfDirectory(
        at: node.url,
        includingPropertiesForKeys: [.isDirectoryKey],
        options: [.skipsHiddenFiles])) ?? []
    let nodes = urls
        .filter { !IgnoreRules.shouldIgnore($0) }
        .map { FileNode(url: $0, isDirectory: (try? $0.resourceValues(forKeys: [.isDirectoryKey]))?.isDirectory ?? false) }
        .sorted { ($0.isDirectory ? 0 : 1, $0.name.lowercased()) < ($1.isDirectory ? 0 : 1, $1.name.lowercased()) }
    node.children = nodes
    return nodes
}
```

## Bước 4 - Cell Và Selection

- `viewFor` trả `NSTableCellView` với icon (`NSWorkspace.shared.icon`) + tên.
- `outlineViewSelectionDidChange` lấy node đang chọn, callback lên SwiftUI (Combine hoặc closure) để mở viewer.

## Bước 5 - Ignore Rules

- `IgnoreRules.shouldIgnore(_ url:)` bỏ `.git`, `node_modules`, `.build`, `DerivedData`.
- Danh sách cấu hình được, mặc định cứng ở M1.

## Bước 6 - File Viewer (TextKit 2)

- `NSTextView` trên macOS 12+ mặc định dùng TextKit 2 (viewport layout, tốt cho file lớn).
- Read-only: `isEditable = false`, `isSelectable = true`.
- Monospaced: `NSFont.monospacedSystemFont(ofSize:weight:)`.
- Không wrap để đọc code: tắt line wrapping (`textContainer.widthTracksTextView = false`, `maxSize` lớn).
- Bọc `NSScrollView` + `NSTextView` qua `NSViewRepresentable`.

```swift
let tv = NSTextView(usingTextLayoutManager: true)   // ep TextKit 2
tv.isEditable = false
tv.font = .monospacedSystemFont(ofSize: 12, weight: .regular)
```

## Bước 7 - Đọc File An Toàn

- `FileLoader.load(url:)` trả một enum: `.text(String)`, `.binary`, `.tooLarge(bytes)`, `.error`.
- Giới hạn size (ví dụ 2 MB): vượt thì load phần đầu hoặc báo tooLarge.
- Phát hiện binary: có null byte trong N KB đầu -> `.binary`.

```swift
enum FileContent { case text(String); case binary; case tooLarge(Int); case error(String) }

static func load(url: URL, limit: Int = 2_000_000) -> FileContent {
    guard let size = try? url.resourceValues(forKeys: [.fileSizeKey]).fileSize else { return .error("stat") }
    if size > limit { return .tooLarge(size) }
    guard let data = try? Data(contentsOf: url) else { return .error("read") }
    if data.prefix(8192).contains(0) { return .binary }
    return .text(String(decoding: data, as: UTF8.self))
}
```

## Bước 8 - Gắn Vào WorkspaceView

- Layout split: `HSplitView` với FileTreeView bên trái, FileViewer bên phải.
- Root của cây = workspace path (M0 `state.path`).
- Chọn file -> `FileLoader.load` -> render theo case (text/binary/tooLarge).

## Acceptance M1

- Mở workspace: cây hiện root, chưa scan toàn repo.
- Expand folder: mới đọc nội dung folder đó, cuộn mượt.
- `.git`, `node_modules` không hiện.
- Click file text: nội dung read-only, monospaced, không wrap.
- File > 2 MB: báo tooLarge, không treo.
- File binary: placeholder, không rác ký tự.
