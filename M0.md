# M0 - App Skeleton Và Workspace Persistence

Các bước code cụ thể cho mốc M0 trong `PLAN.md`. Mục tiêu: mở app -> mở folder qua NSOpenPanel -> lưu path ra JSON -> mở lại app tự load workspace cũ.

Xong khi: đóng app, mở lại, workspace cũ tự hiện mà không cần chọn lại.

## Cấu Trúc File

```text
Atelier/
  AtelierApp.swift          // @main, App lifecycle
  WorkspaceStore.swift      // load/save state, resolve bookmark
  WorkspaceState.swift      // model Codable
  ContentView.swift         // root view, empty state vs workspace
  OpenFolder.swift          // NSOpenPanel + security-scoped bookmark
```

## Bước 1 - App Entry

- Tạo SwiftUI App target (Xcode: macOS App, interface SwiftUI, hoặc SPM executable + `@main`).
- `AtelierApp` dùng `WindowGroup`, giữ một `WorkspaceStore` qua `@StateObject`.

```swift
@main
struct AtelierApp: App {
    @StateObject private var store = WorkspaceStore()
    var body: some Scene {
        WindowGroup {
            ContentView().environmentObject(store)
        }
    }
}
```

## Bước 2 - Model State

- `WorkspaceState: Codable` giữ path và bookmark data.
- Bookmark cần cho quyền truy cập lại folder sau khi khởi động (kể cả khi chưa sandbox, để nhất quán).

```swift
struct WorkspaceState: Codable {
    var path: String
    var bookmark: Data?
    var lastOpenedAt: Date
}
```

## Bước 3 - Persistence Ra JSON

- Lưu tại `~/Library/Application Support/Atelier/state.json`.
- `WorkspaceStore: ObservableObject` với `@Published var current: WorkspaceState?`.
- `load()` gọi lúc init, `save()` gọi mỗi khi `current` đổi.

```swift
final class WorkspaceStore: ObservableObject {
    @Published var current: WorkspaceState?
    private let fileURL: URL   // Application Support/Atelier/state.json

    init() { load() }

    func load() { /* đọc JSON, decode, resolve bookmark, gán current */ }
    func save() { /* encode current -> ghi atomic ra fileURL */ }
}
```

- Tạo thư mục Application Support/Atelier nếu chưa có (`FileManager.createDirectory`).
- Ghi atomic (`Data.write(to:options:.atomic)`).

## Bước 4 - Mở Folder

- `NSOpenPanel` với `canChooseDirectories = true`, `canChooseFiles = false`, `allowsMultipleSelection = false`.
- Sau khi chọn: tạo security-scoped bookmark từ URL.

```swift
func pickFolder() -> WorkspaceState? {
    let panel = NSOpenPanel()
    panel.canChooseDirectories = true
    panel.canChooseFiles = false
    panel.allowsMultipleSelection = false
    guard panel.runModal() == .OK, let url = panel.url else { return nil }
    let bookmark = try? url.bookmarkData(
        options: .withSecurityScope,
        includingResourceValuesForKeys: nil,
        relativeTo: nil)
    return WorkspaceState(path: url.path, bookmark: bookmark, lastOpenedAt: Date())
}
```

## Bước 5 - Resolve Khi Khởi Động

- Trong `load()`, sau khi decode: resolve bookmark về URL, gọi `startAccessingSecurityScopedResource()`.
- Nếu bookmark stale hoặc folder không còn: bỏ `current`, về empty state.

```swift
var stale = false
if let data = state.bookmark,
   let url = try? URL(resolvingBookmarkData: data,
                      options: .withSecurityScope,
                      relativeTo: nil,
                      bookmarkDataIsStale: &stale) {
    _ = url.startAccessingSecurityScopedResource()
    // dùng url làm workspace root
}
```

## Bước 6 - Root View

- `ContentView` đọc `store.current`.
- `current == nil`: empty state, nút "Mở Folder" gọi `pickFolder()` rồi gán `store.current` + `store.save()`.
- `current != nil`: hiển thị tên folder trên title bar, placeholder cho các panel M1-M4.

```swift
struct ContentView: View {
    @EnvironmentObject var store: WorkspaceStore
    var body: some View {
        if let ws = store.current {
            WorkspaceView(state: ws)   // placeholder cho M1+
        } else {
            EmptyStateView()           // nút Open Folder
        }
    }
}
```

## Acceptance M0

- Lần đầu chạy: empty state, có nút mở folder.
- Chọn folder: title hiện tên folder, `state.json` được ghi.
- Đóng và mở lại app: workspace cũ tự load, không cần chọn lại.
- Folder bị xóa/di chuyển: app về empty state, không crash.

## Ghi Chú

- Chưa cần entitlement sandbox ở M0. Nếu bật sandbox sau, thêm `com.apple.security.files.user-selected.read-write` và giữ security-scoped bookmark (đã làm sẵn ở đây).
- Gọi `stopAccessingSecurityScopedResource()` khi đổi workspace để tránh rò resource.
